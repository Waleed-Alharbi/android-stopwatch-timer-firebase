# Stopwatch & Timer Android App

An Android application that provides a stopwatch and timer with user authentication and lap tracking using Firebase.

## Features

- User login and signup
- Stopwatch with lap recording
- Timer functionality
- Firebase Authentication
- Firebase Realtime Database
- Clean Android UI
